## Executive Overview & Problem Definition

### 1. The Core Challenge
Remote Sensing Earth Observation (EO) data collected by ISRO satellites (Cartosat, EOS series, Sentinel, RISAT) is vital for agriculture, disaster response, urban planning, defense, and environmental monitoring. However, extracting actionable insight from raw satellite data currently requires specialized GIS tools (ArcGIS, QGIS), deep remote-sensing expertise, complex band-math calculations, and manual multi-sensor correlation. Non-experts—such as disaster relief commanders, district magistrates, or agricultural officers—cannot query raw satellite feeds using simple, natural-language questions.

### 2. Why Standard LLMs / Commercial VLMs Fail
Generic Vision-Language Models (GPT-4o, Claude 3.5 Sonnet, Gemini 1.5 Pro) are trained on standard RGB web imagery (8-bit JPEGs, sub-megapixel resolutions, natural scene perspective). When applied to satellite remote sensing, standard VLMs fail due to six fundamental bottlenecks:

1. **Quantization & Format Loss:** Standard VLMs only accept RGB JPEGs. Converting 16-bit multi-spectral GeoTIFFs (with 12+ spectral bands) to 8-bit RGB discards 95% of critical physical data (Near-Infrared, Short-Wave Infrared, Red-Edge).
2. **Ignorance of Synthetic Aperture Radar (SAR):** Optical sensors cannot penetrate cloud cover or smoke during monsoons or industrial fires. Sentinel-1 / RISAT C-band SAR provides all-weather imaging, but SAR data consists of phase and backscatter intensity (VV/VH polarizations) that generic VLMs mistake for random visual noise.
3. **Lack of Geographic Coordinates (CRS):** Commercial VLMs output pixel coordinates (e.g., `x: 320, y: 450`). They cannot map pixel coordinates to real-world geospatial coordinates (EPSG:4326 / WGS84 latitude/longitude) without GIS CRS transforms.
4. **Single-Frame Isolation:** Tactical remote-sensing questions (e.g., *"How much land was inundated between July 10 and August 2?"*) require joint reasoning over bi-temporal image pairs. Standard VLMs analyze images independently and hallucinate change detection.
5. **Hallucination of Fine Features:** Generic VLMs misidentify agricultural plots, narrow access roads, and waterlogging due to spatial resolution mismatch.
6. **No Tool Execution:** Standard VLMs cannot invoke spatial calculations (e.g., calculating NDWI, computing flooded area in square kilometers, generating vector spatial masks).

### 3. Proposed Solution: SatQuery AI
**SatQuery AI** is an agentic, multimodal vision-language intelligence platform specifically engineered for remote sensing. It bridges natural language understanding with native geospatial raster processing, multi-spectral index calculation, C-band SAR analysis, bi-temporal Siamese change detection, and dynamic MapLibre GL 3D vector visual grounding.

### Module 1: Native GeoTIFF & Band-Math Ingestion Engine (`raster_engine.py`)

This Python module parses 16-bit multi-spectral GeoTIFFs, computes physical spectral indices (NDWI, NDVI), processes Sentinel-1 SAR amplitude images, and outputs normalized arrays with geographic bounds.

```python
import rasterio
from rasterio.warp import transform_bounds
import numpy as np
import cv2
import json

class RemoteSensingRasterEngine:
    def __init__(self, file_path):
        self.file_path = file_path
        self.dataset = rasterio.open(file_path)
        self.crs = self.dataset.crs
        self.bounds = self.dataset.bounds
        # Convert bounds to EPSG:4326 (WGS84) for map visualization
        self.wgs84_bounds = transform_bounds(self.crs, 'EPSG:4326', *self.bounds)
        self.num_bands = self.dataset.count
        self.height = self.dataset.height
        self.width = self.dataset.width

    def extract_optical_indices(self):
        """
        Calculates Normalized Difference Water Index (NDWI) and NDVI
        Sentinel-2: Band 3 = Green, Band 4 = Red, Band 8 = NIR
        """
        if self.num_bands >= 4:
            # Read bands as float32 to prevent overflow
            green = self.dataset.read(2).astype(np.float32) if self.num_bands >= 3 else self.dataset.read(1).astype(np.float32)
            red = self.dataset.read(3).astype(np.float32) if self.num_bands >= 3 else self.dataset.read(1).astype(np.float32)
            nir = self.dataset.read(4).astype(np.float32) if self.num_bands >= 4 else self.dataset.read(1).astype(np.float32)

            # NDWI = (Green - NIR) / (Green + NIR)
            ndwi_denom = green + nir
            ndwi_denom[ndwi_denom == 0] = 1e-8
            ndwi = (green - nir) / ndwi_denom

            # NDVI = (NIR - Red) / (NIR + Red)
            ndvi_denom = nir + red
            ndvi_denom[ndvi_denom == 0] = 1e-8
            ndvi = (nir - red) / ndvi_denom

            water_mask = (ndwi > 0.15).astype(np.uint8)
            veg_mask = (ndvi > 0.35).astype(np.uint8)

            return {
                "ndwi": ndwi,
                "ndvi": ndvi,
                "water_mask": water_mask,
                "water_area_sqkm": float(np.sum(water_mask) * (self.dataset.res[0] * self.dataset.res[1]) / 1e6)
            }
        else:
            raise ValueError("Insufficient spectral bands for Optical index calculation.")

    def process_sar_cband(self):
        """
        Processes Sentinel-1 C-band SAR backscatter (VV/VH polarization).
        Applies Speckle Filter (Lee Filter) and decibel (dB) scaling.
        """
        sar_raw = self.dataset.read(1).astype(np.float32)
        # Convert intensity to decibel scale: dB = 10 * log10(DN^2)
        sar_raw[sar_raw <= 0] = 1e-5
        sar_db = 10 * np.log10(sar_raw)

        # Apply Speckle Noise Reduction (Median Blur / Lee Filter approximation)
        sar_filtered = cv2.medianBlur(sar_db, 5)

        # Water bodies exhibit specular reflection (very low SAR backscatter <-18 dB)
        sar_water_mask = (sar_filtered < -18.0).astype(np.uint8)

        return {
            "sar_db": sar_filtered,
            "sar_water_mask": sar_water_mask,
            "all_weather_water_area_sqkm": float(np.sum(sar_water_mask) * (self.dataset.res[0] * self.dataset.res[1]) / 1e6)
        }

    def pixel_to_geo_coords(self, px_min, py_min, px_max, py_max):
        """
        Converts pixel bounding box coordinates to real WGS84 Lat/Lon Bounding Polygon.
        """
        transform = self.dataset.transform
        lon_min, lat_max = transform * (px_min, py_min)
        lon_max, lat_min = transform * (px_max, py_max)

        geojson_polygon = {
            "type": "Feature",
            "geometry": {
                "type": "Polygon",
                "coordinates": [[
                    [lon_min, lat_max],
                    [lon_max, lat_max],
                    [lon_max, lat_min],
                    [lon_min, lat_min],
                    [lon_min, lat_max]
                ]]
            },
            "properties": {
                "bbox_wgs84": [lon_min, lat_min, lon_max, lat_max]
            }
        }
        return geojson_polygon
```

### Module 2: Bi-Temporal Siamese Change Detection Engine (`change_engine.py`)

Compares two temporal GeoTIFF rasters (T1 = Pre-Disaster, T2 = Post-Disaster) to produce exact change vector masks and quantitative difference reports.

```python
import numpy as np
import cv2

class BiTemporalChangeEngine:
    def __init__(self, t1_raster_path, t2_raster_path):
        self.t1_engine = RemoteSensingRasterEngine(t1_raster_path)
        self.t2_engine = RemoteSensingRasterEngine(t2_raster_path)

    def compute_inundation_change(self):
        """
        Detects newly flooded land by subtracting T1 water mask from T2 water mask.
        """
        t1_indices = self.t1_engine.extract_optical_indices()
        t2_indices = self.t2_engine.extract_optical_indices()

        t1_water = t1_indices["water_mask"]
        t2_water = t2_indices["water_mask"]

        # Newly flooded area = (Water in T2) AND NOT (Water in T1)
        new_inundation = np.logical_and(t2_water == 1, t1_water == 0).astype(np.uint8)

        resolution = self.t2_engine.dataset.res[0] # meters per pixel
        pixel_area_sqm = resolution * resolution
        newly_flooded_sqkm = float(np.sum(new_inundation) * pixel_area_sqm / 1e6)

        # Extract contours to build vector polygons
        contours, _ = cv2.findContours(new_inundation, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
        geojson_features = []

        for cnt in contours:
            if cv2.contourArea(cnt) > 20: # Filter small noise artifacts
                x, y, w, h = cv2.boundingRect(cnt)
                poly = self.t2_engine.pixel_to_geo_coords(x, y, x + w, y + h)
                poly["properties"]["change_type"] = "Newly Inundated Land"
                poly["properties"]["area_ha"] = float(cv2.contourArea(cnt) * pixel_area_sqm / 10000.0)
                geojson_features.append(poly)

        return {
            "newly_flooded_sqkm": newly_flooded_sqkm,
            "change_geojson": {
                "type": "FeatureCollection",
                "features": geojson_features
            }
        }
```

### Module 3: LangGraph Agentic Orchestrator & Tool Router (`agent_router.py`)

An autonomous agent that inspects user queries, determines the required spatial tool workflow, executes raster computations, and returns structured multimodal answers.

```python
from typing import TypedDict, Annotated, List, Dict, Any
from langgraph.graph import StateGraph, END
import json

class AgentState(TypedDict):
    user_query: str
    input_mode: str # 'single_image', 'cross_modal_pair', 'bitemporal_pair'
    t1_image_path: str
    t2_image_path: str
    sar_image_path: str
    detected_intent: str
    raster_metrics: Dict[str, Any]
    geojson_output: Dict[str, Any]
    final_response_text: str

# 1. Intent Recognition Node
def intent_classifier_node(state: AgentState):
    query = state["user_query"].lower()
    if "change" in query or "flood extent" in query or "between" in query or "compare" in query:
        state["detected_intent"] = "BITEMPORAL_CHANGE_DETECTION"
        state["input_mode"] = "bitemporal_pair"
    elif "cloud" in query or "sar" in query or "radar" in query or "all-weather" in query:
        state["detected_intent"] = "CROSS_MODAL_SAR_FUSION"
        state["input_mode"] = "cross_modal_pair"
    else:
        state["detected_intent"] = "SINGLE_IMAGE_VQA"
        state["input_mode"] = "single_image"
    return state

# 2. Tool Execution Router Node
def spatial_tool_executor_node(state: AgentState):
    intent = state["detected_intent"]

    if intent == "BITEMPORAL_CHANGE_DETECTION":
        change_engine = BiTemporalChangeEngine(state["t1_image_path"], state["t2_image_path"])
        res = change_engine.compute_inundation_change()
        state["raster_metrics"] = {"newly_flooded_sqkm": res["newly_flooded_sqkm"]}
        state["geojson_output"] = res["change_geojson"]

    elif intent == "CROSS_MODAL_SAR_FUSION":
        engine = RemoteSensingRasterEngine(state["sar_image_path"])
        sar_res = engine.process_sar_cband()
        state["raster_metrics"] = {"all_weather_water_sqkm": sar_res["all_weather_water_area_sqkm"]}
        state["geojson_output"] = {"type": "FeatureCollection", "features": []}

    else: # SINGLE_IMAGE_VQA
        engine = RemoteSensingRasterEngine(state["t1_image_path"])
        opt_res = engine.extract_optical_indices()
        state["raster_metrics"] = {"water_area_sqkm": opt_res["water_area_sqkm"]}
        state["geojson_output"] = {"type": "FeatureCollection", "features": []}

    return state

# 3. Response Synthesizer Node
def response_synthesizer_node(state: AgentState):
    intent = state["detected_intent"]
    metrics = state["raster_metrics"]

    if intent == "BITEMPORAL_CHANGE_DETECTION":
        sqkm = metrics.get("newly_flooded_sqkm", 0.0)
        state["final_response_text"] = (
            f"**SatQuery AI Bi-Temporal Analysis Report:**\n\n"
            f"• **Analysis Mode:** Bi-Temporal Optical Change Detection\n"
            f"• **Newly Inundated Area:** `{sqkm:.2f} sq. km`\n"
            f"• **Vector Polygon Output:** Exported {len(state['geojson_output']['features'])} spatial bounding polygons.\n"
            f"• **Recommendation:** Immediate flood relief deployment recommended for highlighted vector clusters."
        )
    elif intent == "CROSS_MODAL_SAR_FUSION":
        sqkm = metrics.get("all_weather_water_sqkm", 0.0)
        state["final_response_text"] = (
            f"**SatQuery AI Cloud-Penetrating SAR Report:**\n\n"
            f"• **Sensor Used:** Sentinel-1 C-Band Synthetic Aperture Radar (VV Polarization)\n"
            f"• **Cloud Cover Impact:** 0% (SAR penetrates dense monsoon cloud layers)\n"
            f"• **Detected Water Surface:** `{sqkm:.2f} sq. km`"
        )
    else:
        sqkm = metrics.get("water_area_sqkm", 0.0)
        state["final_response_text"] = (
            f"**SatQuery AI Single Image Analysis:**\n\n"
            f"• **Calculated NDWI Water Extent:** `{sqkm:.2f} sq. km`"
        )

    return state

# Build Graph Workflow
graph_builder = StateGraph(AgentState)
graph_builder.add_node("classifier", intent_classifier_node)
graph_builder.add_node("executor", spatial_tool_executor_node)
graph_builder.add_node("synthesizer", response_synthesizer_node)

graph_builder.set_entry_point("classifier")
graph_builder.add_edge("classifier", "executor")
graph_builder.add_edge("executor", "synthesizer")
graph_builder.add_edge("synthesizer", END)

satquery_agent = graph_builder.compile()
```

```python
import torch
from transformers import AutoProcessor, Qwen2VLForConditionalGeneration
from peft import LoraConfig, get_peft_model
from datasets import load_dataset

def train_satquery_vlm_adapter():
    model_id = "Qwen/Qwen2-VL-7B-Instruct"
    
    # 1. Load processor and model in 4-bit quantization
    processor = AutoProcessor.from_pretrained(model_id)
    model = Qwen2VLForConditionalGeneration.from_pretrained(
        model_id,
        torch_dtype=torch.bfloat16,
        device_map="auto",

        bias="none",
        task_type="CAUSAL_LM"
```

## Risk Matrix & Mitigation Tactics

| Identified Risk | Risk Severity | Concrete Mitigation Strategy |
|---|---|---|
| **Satellite File Size Too Large (>500MB GeoTIFF)** | High | Pre-crop GeoTIFFs to 1024x1024 spatial chips (`rio-clip`) or serve compressed Cloud-Optimized GeoTIFFs (COGs). |
| **GPU Out-of-Memory during VLM Inference** | Medium | Quantize model to 4-bit (bitsandbytes / Ollama Qwen2-VL 4-bit) or fallback to Florence-2-large (0.7B parameters). |
| **Live Satellite API Latency / Rate Limits** | Medium | Cache historical Sentinel-1/2 GeoTIFF samples locally in `/data/samples/` for instantaneous live demo execution. |
| **SAR Noise & Speckle Distortion** | Low | Apply Lee Speckle Filter (5x5 median blur window) and normalized decibel scaling (-18 dB water cutoff). |
